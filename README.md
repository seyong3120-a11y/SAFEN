 SAFEN | 개인정보 보호 캠페인

> 작은 확인으로, 더 안전한 일상.

일상에서 무심코 남기는 개인정보를 다시 살펴보고, 쉽게 실천할 수 있는 보호 방법을 알려주는 캠페인 웹사이트입니다. 개인정보 보호라는 주제를 어렵게 설명하기보다 영상과 이미지, 짧은 안내 문구로 전달하고 싶었습니다.

웹디자인과 퍼블리싱을 공부하며 만든 포트폴리오 프로젝트입니다.

## 제작 방향

- 캠페인 소개에서 보호 가이드, 자주 묻는 질문으로 자연스럽게 이동하도록 구성했습니다.
- 계정 관리, SNS 공유, 택배와 서류 처리처럼 일상에서 접하기 쉬운 상황을 콘텐츠로 정리했습니다.
- 네이비와 아이보리를 중심으로 차분한 분위기를 만들고, 연한 파란색으로 안내 영역을 구분했습니다.
- PC뿐 아니라 모바일에서도 내용을 읽고 메뉴를 이용할 수 있도록 반응형으로 작업했습니다.

## 사용 기술

| 기술 | 활용 내용 |
| --- | --- |
| HTML5 | 페이지 구조, 영상, 내비게이션, 탭과 검색 영역 구성 |
| CSS3 | 페이지별 레이아웃, 반응형 스타일, 호버와 펼침 효과 |
| JavaScript | 모바일 메뉴, 가이드 탭, FAQ 검색·필터·아코디언, 스크롤 이동 |
| Pretendard Variable | 본문 웹폰트 적용 |

별도의 프레임워크나 npm 설치 없이 실행하는 정적 웹 프로젝트입니다.

## 페이지 구성

| 페이지 | 주요 내용 |
| --- | --- |
| `index.html` | 캠페인 소개, 메인 영상, 생활 속 보호 습관, 가이드·FAQ 연결 |
| `guide.html` | 캠페인 영상, 계정·로그인 / 일상 속 개인정보 / 사기·유출 대응 가이드 |
| `faq.html` | 질문 20개, 카테고리 필터, 검색, 답변 펼치기 |

## 구현한 기능

### 공통 메뉴와 TOP 버튼

모바일에서 햄버거 버튼으로 메뉴를 열고 닫도록 만들었습니다. 메뉴 바깥을 클릭하거나 Escape 키를 눌러도 닫히도록 처리했습니다. TOP 버튼을 누르면 페이지 맨 위로 이동합니다.

### 영상과 스크롤 이동

메인에는 음소거 상태로 자동 재생되는 반복 영상을 배치했습니다. 보호 가이드에도 캠페인 영상을 넣었습니다. 메인 첫 영역에서 아래로 휠을 움직이면 다음 소개 영역으로 이동하도록 구현했습니다. 페이지 전체를 한 섹션씩 이동시키는 방식은 아닙니다.

### 보호 가이드 탭

가이드 내용을 세 가지 주제로 나눴습니다.

- 계정·로그인
- 일상 속 개인정보
- 사기·유출 대응

선택한 탭에 맞는 내용만 표시하고, 주소의 해시와 탭 상태를 연결했습니다. 좌우 방향키와 Home·End 키로도 탭을 선택할 수 있도록 작업했습니다.

### FAQ 검색과 카테고리 필터

JavaScript 배열에 질문과 답변 20개를 정리하고 화면에 표시했습니다. 전체, 계정·비밀번호, SNS·사진, 앱·기기, 문자·피싱으로 분류했습니다. 카테고리와 검색어를 함께 적용할 수 있고, 질문과 답변의 내용을 검색합니다. 검색 결과 개수와 결과가 없을 때의 안내도 표시합니다.

질문을 누르면 해당 답변이 펼쳐집니다. 다른 질문의 답변을 자동으로 닫는 방식이 아니라 여러 답변을 함께 열어볼 수 있습니다.

### 키보드 사용을 고려한 처리

본문 바로가기 링크와 탭·아코디언의 ARIA 속성을 넣었습니다. 움직임을 줄이도록 설정한 환경에서는 일부 스크롤과 애니메이션 효과를 줄이도록 처리했습니다.

첨부본에는 별도 개인 포트폴리오 폴더도 포함되어 있습니다. 위 설명은 SAFEN 캠페인 페이지를 기준으로 작성했습니다.

## 실행 방법

1. 압축을 풀고 `index.html`이 있는 SAFEN 폴더를 VS Code로 엽니다.
2. Live Server 확장 기능을 설치합니다.
3. `index.html`을 우클릭하고 **Open with Live Server**를 선택합니다.
4. 헤더 메뉴에서 보호 가이드와 FAQ 페이지로 이동합니다.

## 작업하며 배운 점

- 공통 스타일과 페이지별 스타일을 나누면 수정할 위치를 찾기 쉬웠습니다.
- FAQ를 배열로 관리하면서 같은 구조의 요소를 JavaScript로 반복 생성하는 방법을 연습했습니다.
- 검색과 카테고리 조건을 함께 적용하며 배열의 `filter()` 사용법을 익혔습니다.
- 탭을 바꿀 때 화면 표시뿐 아니라 선택 상태와 키보드 포커스도 함께 관리해야 한다는 점을 배웠습니다.
- 모바일에서는 글자 크기와 여백, 카드 배치를 따로 조절하는 과정이 필요했습니다.

## 보완하고 싶은 부분

- FAQ 일부 문장의 오탈자와 질문·답변의 연결을 다시 다듬고 싶습니다. 이벤트 참여 질문과 앱 권한 질문은 답변을 더 구체적으로 정리할 필요가 있습니다.
- 개인정보 보호 안내에 참고한 공식 자료와 출처를 정리하고 싶습니다.
- 실제 기기에서 영상 로딩 속도와 메뉴·탭 사용성을 추가로 확인하고 싶습니다.
- 이미지와 영상 용량을 줄여 처음 접속했을 때의 로딩을 개선하고 싶습니다.

## 확인 범위와 안내

첨부된 소스에서 3개 페이지, 가이드 탭 3개, FAQ 데이터 20개, 반응형 CSS와 영상 파일을 확인했습니다. 주요 HTML에서 참조하는 로컬 파일은 압축파일 안에 존재합니다. 브라우저에서의 실제 재생과 모든 화면 크기의 동작 검증을 완료했다는 의미는 아닙니다.

공식 기관에서 운영하는 사이트가 아닌 포트폴리오용 캠페인 프로젝트입니다. 개인정보를 수집하거나 계정 보안을 직접 변경하는 기능은 없습니다. 제작 기간, 팀 구성, 개인 담당 범위와 배포 주소는 확인 가능한 정보를 바탕으로 별도 기재할 예정입니다.

폰트 라이선스는 `fonts/LICENSE.txt`에서 확인할 수 있습니다. 이미지와 영상의 제작·이용 출처는 별도로 정리할 예정입니다.
